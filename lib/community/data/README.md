# Справочник населённых пунктов

Фиксированный локальный снимок на 21.10.2026: 1316 кодов CBS. Источники, дата изменения государственного ресурса, точные адреса, запрос и SHA256 — в SOURCE.json.

Основа кодов/ивритских и английских названий — [официальный обновляемый список PIBA](https://data.gov.il/dataset/citiesandsettelments), ресурс `8f714b6f-c35c-4b40-a0e7-547b675eee0e`, файл от19.10.2026. Русские названия дополняются по точному CBS-коду из [официального объединённого справочника](https://data.gov.il/he/datasets/cio/unified), ресурс e9701dcb-9f1c-43bb-bd44-eb380ade542f. CSV CDN вернул403, поэтому прочитан официальный публичный datastore API того же ресурса. 283 русских названия из этого источника сохранены с приоритетом. В текущем снимке для ещё469 названий использованы русские метки Wikidata, связанные **точным кодом CBS** через [P3466](https://www.wikidata.org/wiki/Property:P3466). Неоднозначные сопоставления пропущены. Догадок по похожим названиям нет.

Всего752 русских названия после точного сопоставления с текущим списком; показатели и источники указаны в SOURCE.json. Для остальных отображается государственное название на иврите; английское название также доступно в результатах. Поиск дополнительно использует русскую транслитерацию английского названия как поисковый вариант; она не объявляется официальным русским названием и не записывается как каноническое значение.

ID — строка кода CBS с ведущими нулями. Каноническое название: русское из снимка, при отсутствии — ивритское. Сервер проверяет пару ID/название. Исторические свободные строки в users.city не сопоставляются и не переписываются автоматически; users.city_id остаётся NULL до явного выбора.

Справочник работает из локального JSON через API приложения; доступность внешних сайтов не влияет на заполнение формы. Для обновления нужен осознанный новый снимок с проверкой неоднозначностей, количества записей и источников. Автоматического фонового обновления в этом релизе нет.
