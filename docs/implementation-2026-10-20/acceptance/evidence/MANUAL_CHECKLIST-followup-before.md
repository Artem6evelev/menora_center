# Непроверенная браузерная часть

Ни один пункт ниже не выполнен браузером. Computer Use отказал до получения UI: `Computer Use permissions are not granted`. SSR/HTTP не засчитываются как прохождение этого списка.

Подготовлены локальные стенды: `http://127.0.0.1:3327` — synthetic DB + mock Clerk для UI/ролей; `http://localhost:3330` — настоящий Clerk **test mode** + отдельная synthetic in-memory БД, уведомления отключены. Оба не используют подключение к реальной БД Menorah. На 3327 cookie `_community_fixture` выбирает `fixture-mom`, `fixture-father`, `fixture-giyur`, `fixture-admin`; это только UI-тестирование, не OAuth. На 3330 аккаунт Google ещё не выбран; использовать только разрешённые тестовые аккаунты, личный вход/подтверждение выполняет владелец. Роли/семьи для реальных test Clerk ID подготовить в synthetic БД после их идентификации. Не использовать localhost:3000 с реальной БД для записывающих тестов.

Пройти UI-пункты на desktop 1440×900 и mobile 390×844, дополнительно 320px для узкого экрана. Везде: читаемый текст, доступные кликом и клавиатурой кнопки, корректные переносы, нет горизонтального overflow, сообщения ошибок видны и загрузка завершается.
