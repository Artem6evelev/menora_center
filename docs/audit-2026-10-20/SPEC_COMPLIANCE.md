## Ограничения итогов

HTTP snapshot публичного сайта зафиксирован отдельно в [public-http.json](evidence/public-http.json): home и одна прямая ссылка вернули 200, старую гостевую структуру и картинки/метаданные; SHA развёртывания неизвестен. Это подтверждение только перечисленных публичных ответов, не перенос всех локальных findings на production. Клиентская гидратация, viewport, CDN cross-user isolation, OAuth и права реальных аккаунтов не проверялись.

Серверные/интеграционные probes и component renders не меняли реальные данные и не отправляли сообщения. Сведения о старых профилях получены только агрегатами READ ONLY; отсутствие новых полей не объявляется самостоятельным дефектом существующего пользователя без решения D06.
