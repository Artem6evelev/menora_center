# Русский интерфейс и запись за одно нажатие — 08.11.2026

Подготовлено на чистом `main` поверх `e61f8340e9886704d137b0ab18deb66ff724f6f8`. Новое решение владельца: вся платформа использует русский язык, выбор языка не нужен. Это заменяет требование RU/HE/EN из ТЗ02.11 в соответствующей части. Допуск, дети, identity, CRM-согласия и оплата сохраняют прежние правила.

## Изменения

- После первого «Хочу прийти» сайт сразу проверяет допуск и открывает следующий нужный шаг. У участника с актуальным подходящим профилем — существующая форма записи с семьёй/стоимостью. При необходимости — сразу короткий вопрос, контакт или обычная анкета/вход. Повторного «Хочу прийти» внутри окна нет.
- Автопроверка запускается только после пользовательского CTA. React StrictMode не создаёт двойной запрос. Ошибка даёт русскую кнопку повтора; закрытие прерывает запрос, и запоздалый ответ не открывает форму. «Продолжить просмотр» закрывает окно.
- Убраны переключатели языка из входа на событие, Mini App, контактов и отписки. Website profile и event page больше не читают старую языковую cookie; Mini App игнорирует `lang=en/he`, язык Telegram и браузера. Анкета, навигация и новые сообщения выбирают RU. Неиспользуемые исторические словари сохранены без большого рефакторинга. Clerk website provider уже использует ruRU.
- WhatsApp остаётся +972 50-670-0779. Английская подпись собственной платёжной рамки и Email-label заменены русскими. Внешний интерфейс Google/Shutafim не изменяется этим кодом.
- Проверки допуска выполняются сервером как прежде; предварительный ответ не создаёт билет и не подтверждает оплату. Ни поля схемы, ни миграции, ни production env, ни Telegram webhook/menu в hotfix не меняются.
