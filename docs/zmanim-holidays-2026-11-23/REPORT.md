# Ближайшие праздники на табло зманим — 23.11.2026

База `main`: `7725ce5b155ad9677513e2d6f79e969e6f9ad762`. Дополнение публичной страницы `/zmanim` для постоянного показа на 65-дюймовом телевизоре. Существующее получение времени Chabad, часы, дневные колонки и управление экраном сохранены.

## Что добавлено

- Три ближайшие даты: еврейские праздники, посты, Рош ходеш и 24 хабадские даты. Текущая дата выделяется. На каждый вид праздника — собственные цвета и векторный символ: ханукия, маца, сукка, свиток Торы, скрижали, деревья, свадебные кольца и другие. Основной баннер и выделенная строка меняют оформление в соответствующий день. Посты и дни памяти оформлены спокойно, без поздравлений.
- Гражданская дата начала подписана «С вечера …»; посты с рассвета обозначены отдельно. Еврейский диапазон сохраняет все дни праздника. При совпадении нескольких дат главный праздник имеет приоритет; календарь не теряет памятную дату. Ошана Раба и седьмой день Песаха получают отдельное оформление.
- Даты рассчитаны серверной библиотекой `@hebcal/core@6.16.1`, строго для **Израиля**. Песах семь дней, Шавуот один день, Шмини Ацерет и Симхат Тора объединены. Учитываются переносы постов и високосные годы. Свечные события Hebcal не используются как первый день Хануки: фактические восемь дней начинаются 25 Кислева. В високосном году день рождения ребецн Хаи Мушки показан 25 Адара I и II согласно Chabad.
- Хабадские даты взяты из [основного календаря Chabad](https://www.chabad.org/library/article_cdo/aid/357752/jewish/Chabad-Calendar.htm), [дополнительного списка](https://www.chabad.org/library/article_cdo/aid/559301/jewish/Special-Days-on-the-Chassidic-Calendar.htm), [правила двух Адаров](https://www.chabad.org/library/article_cdo/aid/630346/jewish/When-Do-I-Celebrate-My-birthday-in-a-Leap-Year.htm). Израильская продолжительность сопоставлена с [календарём праздников Chabad](https://www.chabad.org/holidays/default_cdo/location/israel/jewish/holidays.htm).
- Зманим по-прежнему **только Chabad.org, Ришон ле-Цион, `1-853`**. Hebcal рассчитывает календарные даты, не время молитв. Начало темы — по опубликованному заходу/рассвету; окончание — по опубликованному ночному времени. Добавлена поддержка настоящего ключа `FastEnds` («Окончание поста»), найденного в реальном ответе Chabad; версия кеша поднята, чтобы старый разбор не скрывал его.
- Даты и темы обновляются автоматически без ежегодной ручной замены. API отдаёт календарь на 400 дней и обновляет его вместе с данными табло. При недоступности Chabad календарь остаётся доступным, но активное оформление без времён не угадывается. Неподходящий по дате календарь не показывается. После полуночи вчерашние времена не используются.
- Календарная библиотека остаётся на сервере: в клиентских chunks нет `@hebcal/core`/`HebrewCalendar`. Клиент получает компактный список дат, а SVG не требуют внешних изображений.
